# レギュレータ過電流時の自動リセット機能追加

## 背景

`/nadb/nadb65/status/mpod/regulator_autoreset/` 配下には、MPODが3秒間隔でカレントを監視し、電流制限を超過した場合のみ `Module-<N>_YYYYMMDD.log` にサンプルを追記するログがある。従来この過電流は自動検知・復旧されておらず、手動でレギュレータ(AP)を入れ直す必要があった。

## 変更内容

- `scripts/mada_regulator_autoreset.py` を新規追加。`RegulatorAutoresetMonitor` クラスが上記ログを1秒間隔でポーリングし、追記された新しい行(=過電流イベント)を検知したら、対応するboardのAPを0→1でリセットする。
  - `MADA_config.json` の `gigaIwaki` 各エントリに追加した `module` フィールド(MPODのモジュール番号)で、ログファイルとboardを対応付ける。
  - 監視開始時点で既存のログ内容(過去の履歴)は読み飛ばし、開始後に追記された行のみを新規イベントとして扱う。
  - 日付が変わってログファイルがローテーションされた場合も追従する。
- `scripts/mada_set_ap.py` の `run_set_ap()` に `target_ip` 引数を追加し、特定boardのみを対象にAP ON/OFFできるようにした(従来は稼働中の全boardが対象)。
- `scripts/mada.py` の `run_daq()` で、レギュレータ有効化(`run_encoder_power_up`)直後に監視スレッドを開始し、無効化(`run_encoder_power_down`)直前に停止するようにした。DAQ実行中(1period分)はこの監視が常時有効になる。
- `config/MADA_config_SKEL.json` の全boardに `module: 2` を追加(現行ハードウェアでは全board共通でMPOD Module-2に接続されているため)。
