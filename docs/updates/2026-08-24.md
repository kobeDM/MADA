# .madaファイル欠損時のRunLogger例外を修正

## 背景

`RunLogger.write_info_end()`は`os.path.getsize()`でファイルサイズを取得しているが、boardとの接続失敗等で`.mada`ファイルが生成されなかった場合、`FileNotFoundError`が送出されRunLogger自体が例外終了していた。この場合、infoファイルへ`end`/`size`が書き込まれず、当該runの記録が不完全なまま残る。

## 変更内容

- `scripts/mada.py`: `write_info_end()`で`.mada`ファイルの存在を`os.path.exists()`で先に確認し、存在しない場合は例外にせず`file_size = 0`として処理を継続するようにした。
  - 該当board名を含むWARNINGを標準出力に出力(`WARNING: <path> not found (connection failure suspected on <board_id>)`)。
  - infoファイルの`runinfo`に`error: "mada file not found (connection failure suspected)"`を追記し、後から欠損runを判別できるようにした。
