# rateログのフォーマット不整合を修正

## 背景

`~/rate/YYYYMMDD`への書き込みが、独立した2つのコードパスから行われていた。

- `scripts/mada.py`の`RunLogger.write_rate_log()`: 1ファイル完了ごとに1行、タブ区切り。列は`t, start, end, rate`(4列)で、`rate`は要求イベント数(`event_num`)を実時間で割った値であり、ボード別の実データではなかった。
- `scripts/mada_daq_killer.py`の`run_daq_killer()`: Ctrl+C割り込み時、アクティブボードの数だけ1行ずつ追記。列は`t, start, end, realtime, rate`(5列、スペース区切り)で、`rate`はボードごとの`.mada`ファイルサイズを実時間で割ったバイトレート。

この2つが最初期の実装以降同期されずに乖離しており、`~/rate`には形式の異なる行が混在していた。さらに、これを読んでInfluxDBへ送る`scripts/mada_log_data_size.py`は`cathode`/`anode`固定2ボードを前提に7列以上を要求しており、上記どちらの形式もこれを満たさないため、実際には一度もInfluxDBへのデータ送信に成功していなかった。

なお、最初期の実装(`276eb86`)では`t, start, end, size_1..N, rate_1..N`という可変長のボード別形式が使われており、今回はこれを踏襲する形で統一した。

## 変更内容

- `scripts/mada_rate_log.py`(新規): `write_rate_log(rate_root, start_time, end_time, sizes)`を共通実装として切り出し。列は`t, start, end, size_1..N, rate_1..N`(N=ボード数、`rate_i = size_i / realtime`)。`mada.py`と`mada_daq_killer.py`の両方から利用することで、今後どちらか一方だけが改修されて再び乖離する事態を防ぐ。
- `scripts/mada.py`: `RunLogger.write_info_end()`が全ボード分のサイズを`dict`で返すよう変更(従来は最後のボードの値のみ返していた)。`RunLogger.write_rate_log()`は`mada_rate_log.write_rate_log()`に委譲。
- `scripts/mada_daq_killer.py`: ボードごとに別形式で書いていたループ内書き込みを廃止し、全ボード分のサイズが揃った後に`mada_rate_log.write_rate_log()`を1回だけ呼ぶ。
- `scripts/mada_log_data_size.py`: 固定2ボード(`cathode`/`anode`)を前提にしたパースを廃し、`N = (len(parts) - 3) // 2`で可変長パースするよう変更。ボードIDは行に含まれないため、DAQ側の実際の`MADA_config.json`(`config/MADA_logDataSize.json`の`daq_config`で指定)からアクティブボードの列挙順を読み込み、列位置とboard_id(`GBKB-xx`)を対応付けてInfluxDBの`device`タグに使う。
- `config/MADA_logDataSize.json`: `tags.device`の固定値を削除し、`daq_config`(実DAQ用`MADA_config.json`への絶対パス)を追加。

## 過去データの扱い(補足)

- `~/rate`配下の既存44ファイル(2026/04/30〜08/29分、複数世代のフォーマットが混在)は`~/rate_archive/`へ退避した。
- このうち26日分は、対応するperiodディレクトリの`.info`ファイル(ボード別size/start/endを直接記録)がディスク上に現存していたため、そこから新フォーマットで`~/rate/YYYYMMDD`を再作成した(3510ファイルグループ中3505件、ボード欠損等5件はスキップ)。残り18日分は裏付けとなる`.info`が無いためアーカイブのみに残る。
- InfluxDBについても、上記`.info`ファイルから同様に導出した14032件を`file_size`measurementへ一括投入済み(`mada_log_data_size.py`は前述の通りこれまで一度も送信に成功していなかったため、重複の心配はない)。投入に使った一時スクリプトはリポジトリには残していない。
